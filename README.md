# F1 Strategy Lab

## 1. О проекте

**F1 Strategy Lab** — веб-приложение для анализа реальных гонок Формулы-1 и симуляции альтернативных гоночных стратегий.

Основная идея:

> взять реальную гонку, изменить стратегическое решение — прежде всего момент пит-стопа и состав шин — и оценить, как это могло повлиять на ход и результат гонки.

Проект не пытается идеально воспроизвести всю физику болида или построить официальный прогноз результата. Это аналитический симулятор, который использует реальные исторические данные и упрощённую математическую модель.

### Основной пользовательский сценарий

1. Пользователь выбирает сезон и Гран-при.
2. Выбирает пилота.
3. Просматривает фактическую гонку и стратегию.
4. Меняет параметры стратегии.
5. Запускает симуляцию.
6. Получает альтернативный сценарий.
7. Сравнивает реальную и смоделированную стратегии на графиках и числовых показателях.

# 5. Механизм симуляции

## Общая идея

Симуляция отвечает на вопрос:

> **Что могло бы произойти, если изменить стратегическое решение в конкретной гонке?**

В первой версии проекта симуляция ограничивается стратегией шин и моментами пит-стопов.

---

## Шаг 1. Берём реальную гонку

Для выбранного пилота доступны:

- время каждого круга;
- позиция;
- состав шин;
- возраст комплекта;
- пит-стопы;
- отрыв от других пилотов;
- продолжительность гонки.

---

## Шаг 2. Определяем базовые характеристики

На основе исторических данных оцениваются:

- базовый темп пилота;
- влияние возраста шин на время круга;
- разница между составами;
- потеря времени на пит-стопе;
- изменение темпа в зависимости от состояния шин.

Это не точная физическая модель автомобиля, а приближённая статистическая модель.

---

## Шаг 3. Пользователь меняет стратегию

Например, реальная стратегия:

```text
START: MEDIUM
PIT: LAP 18
      HARD
PIT: LAP 43
      MEDIUM
```

Пользователь может сделать:

```text
START: MEDIUM
PIT: LAP 22
      HARD
PIT: LAP 43
      MEDIUM
```

---

## Шаг 4. Генерируется альтернативный сценарий

Для каждого круга модель пересчитывает ожидаемое время с учётом:

- выбранного состава;
- возраста шин;
- деградации;
- предполагаемого темпа;
- потери времени на пит-лейне.

После этого рассчитывается суммарное время альтернативной гонки.

---

## Шаг 5. Monte Carlo

Для повышения устойчивости результата можно запускать множество вариантов одного сценария.

Например:

```text
1000 симуляций
      |
      +-- случайные небольшие отклонения темпа
      +-- вариация деградации
      +-- вариация потери времени на пит-стопе
      |
      v
распределение возможных результатов
```

В результате система может показать не только одно число, но и диапазон результатов.

Например:

```text
Expected finish: P3
Median race time: ...
Possible finish: P2–P5
```

Это важно, потому что реальная гонка содержит неопределённость.

# 6. Регулируемые параметры

В MVP пользователь может менять:

### Стратегия

- момент первого пит-стопа;
- момент второго пит-стопа;
- количество пит-стопов;
- состав шин на каждом отрезке;
- стартовый состав шин.

### Дополнительно

После реализации базовой модели можно добавить:

- изменение темпа;
- уровень агрессивности;
- степень сохранения шин;
- условный сценарий Safety Car;
- погодные условия;
- VSC.

Расширенные параметры не являются обязательными для первой версии.

# 10. Основная визуализация

Главная задача визуализации — показать **не просто результат, а почему стратегии отличаются**.

Основные графики:

### 1. Position Chart

```text
Position
   |
P1 |----------------
P2 |       -----
P3 |          -----
P4 |
P5 |---
   +------------------ Lap
```

Сравнивает изменение позиции по кругам.

### 2. Lap Time Chart

Показывает:

- фактический темп;
- смоделированный темп;
- деградацию шин.

### 3. Tyre Strategy Timeline

Визуально показывает:

```text
L1                  L20             L40       L55
|-------------------|---------------|---------|
       MEDIUM              HARD        MEDIUM
```

### 4. Strategy Comparison

Накладывает реальный и альтернативный сценарии на один график.

### 5. Simulation Distribution

Для Monte Carlo показывает распределение возможных результатов.

Например:

```text
P2 ███████
P3 ███████████████
P4 ██████████
P5 ████
```

Это позволяет увидеть, насколько результат стратегии устойчив.
